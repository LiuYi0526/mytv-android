# 流光 TV 1.0.0

基于天光云影 3.3.10 继续开发的首个流光 TV 正式版本。

- 首页新增最近观看和设置分类入口，优化卡片、屏幕缩放、焦点滚动与返回位置恢复。
- 支持按键操作映射、定时关闭，改善遥控和触摸操作。
- 订阅源支持扫码与手动双栏添加、M3U 节目单自动识别、播放器 UA 参数及 HTTP Basic 认证。
- 节目单支持独立管理、默认项及订阅关联，改善 XML 解析、频道匹配和跨午夜缓存。
- 完善 DASH ClearKey、Widevine、回看地址模板、动态回看定位和 HLS Cookie 会话传递。
- 支持 MMT/TLV 直播、TTML 字幕及轨道切换；保留 AV3A 音频相关支持。
- Media3 支持 RTSP MP2T、多音轨、跨服务器重定向、UDP 无数据自动转 TCP，以及普通 RTMP。
- 正式 APK 使用独立包名、长期签名和 Android 6.0 最低版本；提供 ARM32、ARM64 及四架构通用包。

## 已知事项

- 不内置个人订阅源；请自行添加订阅。
- RTSP/RTMP 暂不进行线路测速，界面会显示“暂不支持测速”。
- 旧测试应用与流光 TV 使用不同包名，数据不自动共享；请先导出再导入配置。
- 是否可播放仍取决于直播源、网络、服务端鉴权以及设备解码能力。
