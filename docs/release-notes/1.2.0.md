# 流光 TV 1.2.0

本次更新改善直播、时移和回看的操作体验，也让订阅源刷新与节目单显示更稳定。正式版可从 1.1.0 覆盖升级，保留设置和观看记录。

## 播放控制

- 重整播放快捷工具栏。关闭线路等子菜单后，恢复原来的焦点和滚动位置。视轨、音轨和字幕入口会随加载状态更新。
- 进度条支持触摸拖动，遥控左右每次跳 10 分钟。工具栏提供前后 10 秒、上一档、下一档、从头观看和返回直播。
- 回看定位可按订阅源规则重载地址。时移可以续接后面的片段，回看可以续播后续节目，定位到直播点时自动切回直播。
- 支持按频道记忆显示模式，也可设置为跟随全局。播放失败时，在提示窗显示可用的底层错误原因。

## 直播源与解码兼容性

- 支持显式指定 HLS。无扩展名的 HLS 入口可自动识别并复用首次清单响应，减少重复请求。
- 支持按频道配置 Referer、Origin 和 Kodi 链接请求头后缀。Media3 与线路测速也能读取重定向地址中的请求头后缀。
- Media3 支持 ID3 封装的 ARIB STD-B24 字幕、MPEG-TS 杜比视界识别与动态元数据传递，以及带 Common PSSH 的 HLS `cenc` ClearKey。
- 修复部分 HLS WebVTT 字幕引起的播放失败，以及部分 DASH TTML 字幕字号异常。

## 界面与订阅源

- 订阅源过期时先显示旧缓存，再在后台刷新。单次刷新只请求一次，失败时保留旧数据。优化首页启动和节目信息首次加载。
- 节目单空档显示「无信息」。没有 EPG 的频道按小时显示占位，方便浏览时间和定位。
- 统一经典频道列表左右转场，改善节目进度条对比度、长频道名与长节目名显示，加载台标时裁掉外围透明留白。
- 播放器设置可直接编辑 User-Agent 和自定义请求头。时钟「显示秒」默认开启，可在界面设置里关闭。

## 安装与兼容性

- 提供 ARM32、ARM64 和通用包，支持 Android 6.0 及以上。请按设备架构选择安装包。
- 解码、字幕和时移取决于直播源与设备能力。HLS ClearKey 适用于符合上述条件的 `cenc` 流。使用 `cbcs` 的受保护源需要播放器和设备支持的 DRM 与有效授权。
